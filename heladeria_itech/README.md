# Heladería iTECH - versión para alumnos

En esta actividad vas a construir las variables de Python que controlan una heladería digital. La página y su diseño ya están preparados, pero **tu archivo heladeria.py comienza sin respuestas**.

## Abrir la heladería

Abre esta carpeta en VS Code. Debes ver `app.py` directamente en el panel de archivos.

Abre Terminal > New Terminal.

Windows: `py app.py`

Mac: `python3 app.py`

En Chrome abre `http://localhost:8000`. Mantén esa terminal abierta. La página funcionará incluso si todavía no escribiste ninguna variable.

## Trabajar en clase

Abre `practica.py` para los primeros ejercicios con Python.

Después abre `heladeria.py`. Lee las indicaciones y escribe tú las variables que faltan. No es necesario editar `app.py` ni los archivos dentro de `web`.

Guarda con Ctrl + S (Windows) o Cmd + S (Mac). Presiona **Actualizar heladería** en el navegador. Puedes avanzar poco a poco: las variables sin completar muestran ejemplos en la página.

Los nombres de las variables deben ser exactamente: `nombre`, `mensaje`, `sabor1`, `sabor2`, `sabor3`, `color`, `precio`, `descuento`, `precio_final`, `especial`.

## Si aparece un error

Revisa que no falten comillas, que las variables estén escritas igual y que los números de los precios no estén entre comillas. Para el color utiliza `#` seguido de seis dígitos hexadecimales dentro de comillas.

Si la terminal dice que no encuentra `app.py`, abre la carpeta interior `heladeria_itech` y prueba nuevamente.

No necesitas instalar paquetes adicionales ni tener internet para ejecutar la página una vez descargada.
